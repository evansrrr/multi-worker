### 关键技术决策（后续必守）
1. **CSS 变量必须用 `R G B 三元组`，不能用 hex**。Tailwind 3 只能为
   `rgb(var(--x) / <alpha-value>)` 形式的颜色生成 `/50`、`/30` 变体；用 hex 变量时这些类被
   **静默丢弃**（表格分隔线、hover 背景失效），且编译不报错——只能靠查 dist CSS 产物发现。
2. 页面组件不再自包 `<Layout>`，Layout/面包屑/Header 由路由层提供；删 `<Layout>` 时必须同时删
   `</Layout>` 并处理根容器闭合，否则 JSX 会出现多根节点（TS2657）。
3. 品牌色 `cf-orange` 与语义状态色（green/red/blue/amber）不参与 token 化。
4. `useTheme.tsx` 的 fast-refresh warning 与 AuthContext/ToastContext 同型，属可接受存量。

### 关键事实（后续必守）
1. **Pages Direct Upload hash 是 `BLAKE3(base64(内容) + 扩展名).hex()[:32]`，不是 SHA-256**。
   算错会"部署成功但所有资源 404"。Workers 无内置 BLAKE3，引入 `hash-wasm` 依赖。
   协议 4 步：GET upload-token（拿 JWT）→ POST /pages/assets/upload（JWT）→
   POST /pages/assets/upsert-hashes（JWT）→ POST .../deployments（multipart manifest={"path":"hash"}）。
   **未经真实账户端到端验证**（本地无有效 token）。
2. **经典 `/workers/scripts` 不支持分页、无 result_info**（唯一查询参数是 tags），时间字段是
   created_on/modified_on。后端 normalizeScript 把 modified_on??created_on 归一成 updated_on 供前端用。
3. **wrangler 对同 routePath 同名 method 静默覆盖**（Object.assign），`[x].ts` 与 `[x]/index.ts` 不能并存；
   PUT 只能放 `[id].ts` 不能放 `[id]/index.ts`。
