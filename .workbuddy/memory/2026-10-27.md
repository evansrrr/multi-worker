## 全面审查 multi-worker（只分析，未改业务代码）

产出：`AUDIT-2026-10-27.md`（项目根目录），按 高/中/低 优先级整理问题清单，每条含修改方向、风险、工程量；另含基于 Cloudflare API 的功能扩展路线图（F1–F20）与实施顺序。

审查方法：逐文件读 `src/`(33) 与 `functions/`(33)、比对本地 `Cloudflare API Doc/`、跑 `tsc` 验证。

核心结论：
1. Workers 双体系混用：Beta `/workers/workers`（实体）与经典 `/workers/scripts`（脚本+settings）被混着调，创建/部署走错端点，且部署时 `metadata.bindings: []` 会清空全部绑定（H2/H3）。
2. KV 模块三处硬伤：键列表响应结构解析错（`result` 数组 + `result_info.cursor`）、写入手动设 multipart Content-Type 丢 boundary、新建键输入框 disabled 且未受控（H4）。
3. 所有列表忽略 `result_info` 分页 → 每账户只显示前 20 条（H5）。
4. 明暗主题完全失效（useTheme 是组件内 state + 颜色硬编码 cf-dark-*）；移动端无布局（H8）。
5. 导航断裂：WorkerTable/ProjectTable 行不可点进详情、Header 面包屑写死 "Back to Accounts"、KV/D1 选中态不入 URL（H9）。
6. `functions/` 不参与 tsc（tsconfig include 仅 src），已存在 TS2322：`batch/deploy.ts:101`；仓库无 ESLint 配置文件（M9/M10）。
7. 安全：密码无盐 SHA-256、登录无限流、cookie 缺 Secure、加密密钥与密文同存 KV（H1）。

验证记录见 AUDIT 文档第 6 节。
